A — Always-split

Permanent 35/65 split. Detail panel always visible. Navigation stays in list, right panel updates as you move.

Agent Deck ● 2 running ○ 3 waiting ────────────────────────────────────────────────────── SESSIONS ───────────────────────────────────────────────────── ○ mama claude My Sessions 30m ago ● api-work claude My Sessions 2m ago ○ update-design claude My Sessions 5m ago ◐ notes claude My Sessions 12m ago ◐ side-proj claude Research 1h ago Enter Attach Tab Detail n New f Fork x Send q Quit

B — List-first, Tab to expand

Default is full-width list with more sessions visible. Press Tab to slide open a detail panel for the selected session. Toggle back to dismiss.

Agent Deck ● 2 running ○ 3 waiting ─────────────────┬────────────────────────────────────── SESSIONS │ update-design-spec ○ waiting ─────────────── │ my-sessions 30m ago ○ mama │ ● api-work │ ─── Output ────────────────────── ○ update-desi │ Analyzing changes to client.go ◐ notes │ Running tests... ◐ side-proj │ ✓ All tests pass │ > │ [Tab: expand │ v: expand output to full screen output view] │ │ ─── Notes ─────────────────────── │ No notes e to edit Enter Attach v Expand n New f Fork x Send e Notes q Quit

C — Split + expandable output

Always-split like A, but pressing v expands the right panel to full-screen for reading output. Another keypress collapses back to split.
